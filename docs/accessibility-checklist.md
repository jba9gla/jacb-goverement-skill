# Accessibility checklist (run before delivering)

- [ ] Skip link is the first focusable element and works.
- [ ] One h1; headings in order with no skipped levels; page title matches the h1.
- [ ] Every input has a visible label; groups use fieldset and legend; hints linked with aria-describedby.
- [ ] Errors: summary at the top (role="alert") with links to fields; inline message beside each field; title starts "Error:".
- [ ] Whole site usable by keyboard only; focus always visible; no keyboard traps.
- [ ] Text contrast at least 4.5:1 (3:1 for large text and UI borders).
- [ ] Works at 320px wide and at 200% zoom with no horizontal scroll.
- [ ] Touch targets at least 44px.
- [ ] Link text makes sense alone; no "click here".
- [ ] Images have meaningful alt text, or empty alt if decorative.
- [ ] No auto-playing media, carousels or hover-only menus.
- [ ] Colour is never the only signal.
- [ ] Cookie banner: Accept and Reject equally prominent, nothing pre-ticked.
- [ ] Check with a screen reader (VoiceOver or NVDA) on the main journey.
- [ ] Accessibility statement published and linked in the footer.
