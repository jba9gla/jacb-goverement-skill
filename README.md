# GOV.UK-style websites: a Claude skill

A Claude skill for building websites with the clear, accessible look and feel of the GOV.UK Design System: plain English, strong focus states, simple forms.

## Branding
This skill uses the open-source Design System patterns only. It deliberately leaves out the Crown, the GOV.UK logotype and the GDS Transport typeface, which are restricted to UK government services. Sites built with it should carry their own organisation's name and logo and must not pass as an official government service.

## Contents
- `govuk-style-websites/` the skill (SKILL.md) and shared stylesheet
- `templates/html/` 10 ready-to-use page templates
- `templates/kirby/` Kirby templates, snippets and blueprints (Kirby is the recommended CMS)
- `docs/accessibility-checklist.md`
- `VERSION` and `CHANGELOG.md` (current version 1.0.0)

## Install
Add the `govuk-style-websites` folder as a skill in Claude (Settings, Skills), or place it in your skills directory.
